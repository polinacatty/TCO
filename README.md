## Docker

### 1) Требования

- Docker Desktop с включенным Docker Compose
- Свободные порты: `4173`, `8000`, `5432`, `6379`

### 2) Запуск всего проекта

Запусти в корне репозитория:

```bash
docker compose -f docker-compose.yml up -d --build
```

### 3) Инициализация БД и smoke-проверка

**Windows:**

```powershell
powershell -ExecutionPolicy Bypass -File scripts/deployment/run_migrate_and_smoke.ps1
```

**macOS/Linux:**

```bash
bash scripts/deployment/run_migrate_and_smoke.sh
```

## Если что-то не запускается

1. Проверь, что Docker daemon действительно запущен.
2. Посмотри логи сервисов:

```bash
docker compose -f docker-compose.yml logs --tail=200 backend
docker compose -f docker-compose.yml logs --tail=200 frontend
docker compose -f docker-compose.yml logs --tail=200 postgres
docker compose -f docker-compose.yml logs --tail=200 redis
```

3. Проверь, что порты `4173`, `8000`, `5432`, `6379` не заняты другими процессами.

## Методология расчета и подбора автомобиля

### Методология расчета TCO по компонентам

В данном проекте полная стоимость владения автомобилем рассчитывается как сумма компонентных расходов по каждому году горизонта.

Общая формула:

TCO(T) = sum(y=1..T) [ C_dep(y) + C_fuel(y) + C_osago(y) + C_kasko(y) + C_tax(y) + C_maint(y) + C_tyres(y) ]

Где:
- T — горизонт владения в годах
- y — номер года, от 1 до T
- C_dep(y) — амортизационные потери в году y
- C_fuel(y) — расходы на топливо (или электроэнергию) в году y
- C_osago(y) — расходы на ОСАГО в году y
- C_kasko(y) — расходы на КАСКО в году y (если включено)
- C_tax(y) — транспортный налог в году y
- C_maint(y) — расходы на техническое обслуживание в году y
- C_tyres(y) — расходы на шины в году y

#### Амортизация

Амортизационная часть показывает, насколько снижается стоимость автомобиля в процессе владения.

Формулы:

C_dep(y) = P_(y-1) - P_y  
P_y = P_(y-1) * (1 - r_y / 100)  
C_dep(T) = sum(y=1..T) C_dep(y)

Где:
- P_(y-1) — стоимость автомобиля на начало года y
- P_y — стоимость автомобиля на конец года y
- r_y — ставка амортизационного снижения в году y
- C_dep(T) — суммарные амортизационные потери за весь горизонт

#### Топливо

Топливная компонента считается по месяцам внутри каждого года, после чего собирается в годовую сумму.

Формулы:

C_fuel(y) = sum(t=1..12) [ q(y,t) * P_hat(y,t) ]  
q(y,t) = (F_eff * M_y) / (12 * 100)

Где:
- t — номер месяца внутри года
- q(y,t) — расход топлива в месяц t года y
- F_eff — эффективный расход топлива, л/100 км
- M_y — годовой пробег в году y
- P_hat(y,t) — цена топлива в месяц t года y

#### ОСАГО

ОСАГО рассчитывается по нормативной мультипликативной схеме.

Формулы:

C_osago(y) = TB * KT * KBM * KVS * KO * KM * KS  
C_osago(T) = sum(y=1..T) C_osago(y)

Где:
- TB — базовый тариф
- KT — территориальный коэффициент
- KBM — коэффициент бонус-малус
- KVS — коэффициент возраста и стажа
- KO — коэффициент ограничения списка водителей
- KM — коэффициент мощности
- KS — коэффициент сезонности

#### КАСКО

КАСКО в модели является опциональной компонентой и учитывается только при включенном флаге.

Формулы:

C_kasko(y) = (kasko_rate_y / 100) * P_kasko(y)  
C_kasko(T) = sum(y=1..T) C_kasko(y)

Где:
- kasko_rate_y — ставка КАСКО в году y
- P_kasko(y) — стоимость автомобиля, принятая для расчета КАСКО в году y

#### Транспортный налог

Налог считается для каждого года отдельно с учетом мощности, региональной ставки и повышающего коэффициента для дорогих автомобилей.

Формулы:

C_tax(y) = N_hp * tau(region, N_hp) * k_lux(y)  
C_tax(T) = sum(y=1..T) C_tax(y)

Где:
- N_hp — мощность двигателя, л.с.
- tau(region, N_hp) — региональная ставка по диапазону мощности
- k_lux(y) — повышающий коэффициент в году y

#### Техническое обслуживание

Компонента ТО считается как сумма регламентных операций, каждая из которых имеет свою кратность и стоимость.

Формулы:

hits(i,y) = max( floor(total_km(y) / every_km_i), floor(total_months(y) / every_months_i) )  
C_maint(y) = sum(i=1..N) [ hits(i,y) * (parts_i + norm_hours_i * labor_rate_y) ]  
C_maint(T) = sum(y=1..T) C_maint(y)

Где:
- i — индекс операции ТО
- N — количество операций в регламенте
- hits(i,y) — количество выполнений операции i в году y
- parts_i — стоимость запчастей для операции i
- norm_hours_i — трудоемкость операции i в нормо-часах
- labor_rate_y — стоимость нормо-часа в году y

#### Шины

Шинная компонента учитывает покупку новых комплектов по мере износа в течение горизонта расчета.

Формулы:

C_tyres(y) = N_summer(y) * Price_summer + N_winter(y) * Price_winter  
C_tyres(T) = sum(y=1..T) C_tyres(y)

Где:
- N_summer(y) — число покупок летних комплектов в году y
- N_winter(y) — число покупок зимних комплектов в году y
- Price_summer — стоимость одного летнего комплекта
- Price_winter — стоимость одного зимнего комплекта

#### Переменные

- T — горизонт владения автомобилем в годах
- y — номер года в пределах горизонта расчета
- t — номер месяца внутри года
- i — индекс операции технического обслуживания
- C_dep(y) — амортизационные потери в году y
- C_fuel(y) — расходы на топливо в году y
- C_osago(y) — расходы на ОСАГО в году y
- C_kasko(y) — расходы на КАСКО в году y
- C_tax(y) — транспортный налог в году y
- C_maint(y) — расходы на техническое обслуживание в году y
- C_tyres(y) — расходы на шины в году y
